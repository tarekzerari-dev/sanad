# 🤝 Sanad (سند) - Community Support & Assistance Platform

**Sanad** is a lightweight, responsive web application built to connect students and community members with assistance, educational resources, and solidarity initiatives.

---

## ✨ Features

- **🌐 Clean & Accessible Interface**: Designed with intuitive Arabic & English navigation and modern typography.
- **📑 Student & Resource Directory**: Manage student assistance requests, profiles, and solidarity campaigns.
- **⚡ Lightweight & Fast**: Bundled with Vite for instant server start and lightning-fast HMR.
- **☁️ Serverless Storage**: Backed by Netlify Blobs (`@netlify/blobs`) for serverless key-value / document persistence.
- **🛡️ Admin Management**: Dedicated administrative layouts and controls to supervise student submissions and campaigns.

---

## 🛠️ Tech Stack

- **Build Tool**: [Vite](https://vitejs.dev/)
- **Frontend**: Vanilla JavaScript (ES Modules), Modern CSS
- **Backend / Storage**: [Netlify Blobs](https://docs.netlify.com/blobs/overview/)
- **Deployment**: [Netlify](https://www.netlify.com/) (`netlify.toml`)

---

## 🚀 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/tarekzerari-dev/sanad.git
   cd sanad
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
